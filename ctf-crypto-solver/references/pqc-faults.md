# PQC 实现攻击：从故障/侧信道到密钥恢复

当题面出现 **ML-KEM/Kyber、ML-DSA/Dilithium、NTRU、Falcon、HAWK、SDitH、Polar-KEM**
等后量子原语的**实现**，而不是纯数学参数时，漏洞几乎总在实现层：侧信道泄漏、
故障注入、比较/拒绝采样被跳过、nonce 复用、NTT/浮点表示错误。攻击者拿到少量
"hint" 后再回落为格/线性代数恢复。本页是**识别 → 构造 hint → 回落**的流程。

## 1. 先识别原语与攻击面

| 原语 | 常见实现攻击面 | 代表论文（见论文库） |
|---|---|---|
| ML-KEM / Kyber | 解密失败（DF）/明文检查（PC）oracle、FO 比较被跳过、NTT/乘法的侧信道、掩码实现 | 2026/070, 1682, 2069, 820, 2137, 2448 |
| ML-DSA / Dilithium | 拒绝采样被跳过、mask 向量 `y` 的位泄漏、签名水平融合、随机化/确定性模式 | 2026/056, 472, 580, 1344, 1448, 1904, 2567, 2643 |
| NTRU / Falcon | 冷启动、浮点高斯采样泄漏、系数部分恢复 | 2026/582, 2124 |
| HAWK | 采样器泄漏（系数/符号/带噪符号）放大为密钥 | 2026/699, 2381, 1366 |
| 阈值签名（TALUS 等） | 非ce 复用、Feldman 承诺可逆、故障重放 | 2026/1386, 1668, 2566 |

**判断辅助**：题面出现 trace/故障/oracle/“实现被 mask 过”等词 → PQC 实现攻击；
`scripts/papers/search.py --tag ML-DSA` 之类可定位具体论文。

## 2. 通用流程：实现缺陷 → hint → 密钥恢复

```
识别漏洞点 → 提取 hint（每个 hint = 关于密钥的线性/模信息）
     → 组织成 LWE/ILWE/HNP 样本
     → 用格（BKZ/嵌入）或线性代数（最小二乘）恢复密钥
     → 验证（签名/解封装可用）
```

**hint 的三种常见形态**

1. **签名中的线性方程**：ML-DSA 里 `z = y + c·s1`，泄漏 `y` 的若干位/符号就得到
   `s1` 的噪声线性方程；拒绝采样被跳过则 `w1 = A·y` 直接泄漏。→ ILWE / LWE。
2. **Oracle 读数**：DF/PC oracle 把解密噪声逐坐标读出，噪声是密钥的线性函数。
   → 最小二乘或格。相关：2026/070、1682。
3. **部分系数/符号**：Falcon 高斯中心区间、ML-DSA mask 位、HAWK 采样符号。
   → LWE-with-hints（`lwe_hints.sage`）或 Halfspace 学习（2026/1366）。

## 3. 关键：哪些"缺陷"能出题

- **FO 比较未覆盖全部密文字节**（2026/1682）：未比较的尾字节携带解密噪声尾部，
  而噪声是密钥的精确线性函数 → 变密文读噪声，最小二乘恢复。**注意**：即使 `u`
  完全校验也成立。
- **比较流水线中的 Booleanisation 故障**（2026/2069）：单次 clock glitch 令
  mismatch flag=0 → 接受任意密文 → PC oracle → 全密钥。
- **拒绝采样被跳过**（2026/1344、2567）：一条故障签名即可恢复签名密钥。
- **mask 随机数位泄漏**（2026/472、580、1712）：`y` 的单个 bit 泄漏即可逐步恢复
  `s1`；噪声估计（2026/1712）可先修被翻转的位。
- **非ce 复用 / 阈值签名**（2026/1668、2566）：两个 challenge 的响应相减消去 nonce，
  或故障导致跨会话重放。
- **键控值被公开矩阵左乘**（2026/1386）：Feldman 承诺用公开 `A`，而 `A` 左可逆 →
  直接高斯消元恢复。
- **冷启动**（2026/582）：内存位翻转 → 部分系数，用代数关系恢复。

## 4. 回落到哪些工具

| hint 类型 | 回落工具 |
|---|---|
| 噪声线性方程（ILWE） | `lwe_hints.sage`（追加行）/ `lwe_bkz.sage`；`ilwe_bp.sage`（稀疏关系的信念传播求解器，2026/2091、2448 路线） |
| 部分系数/符号 | `lwe_hints.sage`（coord/approx hint）；Halfspace 学习（2026/1366） |
| 精确线性泄漏（无模降） | 最小二乘（普通线性代数） |
| nonce/签名复用 | `hnp_ecdsa.py`、`ctfkit.lattice.ecdsa_partial_nonce_recover` |
| HNP（KAZ 类） | `lwe_bkz.sage` 或 `ctfkit.lattice.hnp_solve` |

## 5. 实战清单

1. 拿到实现：先读**关键检查**（FO 比较、拒绝采样、key 校验）在哪、是否被削弱。
2. 找 **trace/oracle/可注入点**：题目给的输入输出里藏着什么关于密钥的信息。
3. 把信息写成 **`<v,s> = l + e` 的方程**（或非ce 方程）。
4. 判断是模 q 内（LWE）还是整数上（最小二乘），选对工具。
5. 用小规模验证恢复流程，再上真实参数。
